# parse_duration

Write `parse_duration(text: str) -> int` in `solution.py`. It returns the number of seconds in a duration written with the units `h` (hours), `m` (minutes) and `s` (seconds), in that order, each optional but at least one present. Examples: "1h30m" is 5400, "45s" is 45, "2h" is 7200, "1h1m1s" is 3661. Raise ValueError for anything else.
