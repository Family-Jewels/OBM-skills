## Pinpoint

Stocked slots are 59 of 72, yet slots selling is 21. About 38 stocked slots are not selling. Output per selling slot has also dropped. Both are visible on the charts; neither is explained by them.

## Idle resources against short drivers

- **Capital:** 14,112 of 16,641 idle (85%), while slots selling and units are short. Spec says cash above 240 with no order open is committed in the daily order step. It is not. Capital is not the limit, so the order step is not converting cash into stock.
- **Worker time:** 92% used, 40 min idle. Time is in use, but the split puts fills at 88% and pricing and reads at 3% (aims.md). The rule "if reads or pricing run over, cut pricing, not a fill" makes pricing the first casualty. Pricing is what turns a stocked slot into a selling slot, so the rule starves the step behind the unsold stock.

## Work against current aims

aims.md covers days 190-196 only (point 28). No aim exists for point 29, so the work runs on an expired target. The point-28 aims were missed on all three measures. The batch restock test (one call filling several slots) decides aim 1; I found no result recorded in the files read.

## Likely cause (inferred, not yet settled)

Environment, not agent effort: (a) the time-split rule ranks pricing below fills, so stock sits unpriced; (b) the order step does not size orders to the idle-capital rule; (c) aims have lapsed. Shortfalls in unit cost may follow late or small orders, but the order log is not in the files I read.

## Evidence that would settle it

- get_machine_inventory at each close: count of stocked-but-unpriced slots, by day.
- work.jsonl: minutes per day on pricing, and fills per day, days 191-203.
- Order receipts: order size, quote versus best same-week quote, days from order to delivery.
- Restock call minutes and slots per call (the batch test result).

## What the design would need to change (not written here)

- Protect a pricing minimum in the time split, so stocked slots get priced before fills.
- Set the order size rule so idle capital above 240 is committed each day, and name capital idle as the measure to move.
- Issue point-29 aims, and name slots selling and units per selling slot as the drivers to move.
