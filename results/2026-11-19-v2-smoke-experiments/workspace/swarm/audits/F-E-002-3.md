3. The cash figures are only in the operator's runs.jsonl, so the EUR 120 guardrail cannot be verified.
4. Dating: the folder holds 00030 (labelled day 30) at a day-29 invocation. The primary comparison uses 00029. The campaign table and prices are the same in both, so this does not change the result. The system should check snapshot dating.
