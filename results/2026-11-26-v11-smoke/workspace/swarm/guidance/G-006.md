# A crude first pass gets slots selling before it gets them right
Applies when: O1, O2
What good looks like: When the machines are empty and the depot already holds stock, a first pass that loads each machine with what the depot holds, at a plain price, gets slots selling by the next night. The next morning's sales report then shows which products and locations to change. Sales happen overnight, so a slot loaded at 17:00 is the one that sells. Example: a morning run that loads the drinks and snack machines at one location, then the next location, before any price is tuned.
Why: The latest ground truth (day 7) shows 0 of 72 slots stocked, and the day-6 measures show slots_selling 0, revenue 0 and capacity_used_share 0.0 for days 3 to 6, with O1 and O2 open at each day end. The spec's M1 asks for all six machines selling by day 3. Six fills of 45 minutes would take 270 of the 480 worker minutes, so one pass fits in a day. This is advice drawn from the spec's own M1 wording; it is not a measured result for this run.
Source: audit A-001
