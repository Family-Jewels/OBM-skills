## Mismatches and notes (not fail criteria)

1. **Pre-Start baseline missing.** `snapshots/00196.md` (the day before the Start of 197) is not in `swarm/snapshots/`. The earliest snapshot I could read is 00217. I used 00218 as the baseline instead, because it is the last snapshot before the change. Any change to a control unit before day 218 cannot be checked from these snapshots. The change itself, though, happened after 218, and the 218→226 comparison covers it completely, so I did not treat this gap as a failure. Settling it fully would need the day-196 snapshot restored.
2. **Product labels in the spec.** The spec's Change line lists A1 as nuts, A2 as nuts, and B3 as gummy, but the machine has A1 choco (2.10), A2 nuts (2.40), B3 gummy (2.00). The orchestrator flagged this itself. The Change as written (10% on each slot in rows A-B) was applied to the slots as the machine shows them, and the slot-level prices in the spec (2.4, 1.8, 2.1, 2.0) match the machine's slots. This is a spec wording error, not a fidelity failure.
3. **Timing.** The 219 snapshot still showed the old prices; the cut appears by day 226. Timing is not a criterion, so this is recorded only.
4. Record-keeping, cost claims and the cash guardrail were not checked, by design.
