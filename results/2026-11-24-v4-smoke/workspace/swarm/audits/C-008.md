# C-008: controls change, day 56 of 91

## What I changed (swarm/controls.md; prior copy at swarm/history/controls.before-C-008.md)

1. **Price pass floor per stocked slot (REQ-037, REQ-010 via D-011).** The price pass now covers each slot that holds stock, read from today's machine inventory, not a fixed 9. Stocked slots run 5 to 7, so the pass is about 25 to 35 minutes, not 45. Why: D-011 found price setting at 5% of the day against a planned 25%, while restock took about 71% of used minutes. A fixed 9 asks for slots that are empty.
2. **Same-day gate (REQ-010 via D-010 fault 1).** The gate now counts only set_price calls made today. D-010 found the worker counting yesterday's pass, so restock ran first. The 216-minute restock ceiling is unchanged, and so is the rule that the price pass goes first.
3. **Same-day re-quote (REQ-038).** The order gate is unchanged. When an offer has expired, the re-quote (check_offers, then the T-0002 rows) is now the worker's first step that same working day, not something left for the weekly cycle. The text already asked for the re-quote before ordering; the new words close the waiting. Purchasing was gated from day 35 to day 43.
4. **Sales-figure citation (REQ-041 via D-010 fault 2).** A log line stating a day's sales must copy figures from the get_sales_report the worker read that day and carry its date. Why: the day-48 log gave day 48's 21 units and 42.00 as day 47's. The cause is not established; D-010 names the sales report's day label as likely, but the records do not show it. This control is cheap (no extra calls) and guards the record.

Controls not changed: the 216-minute restock ceiling (it is a bound already set by D-009 and REQ-032 turned to an aim restatement for the designer), and the T-0002 check (already in place).

Both existing controls (supplier table, restock ceiling) are at review point 9 and not yet due. The new sales-citation control is at point 9 too.

- I did not stop restock or purchasing. The cash reserve is 3,258 against a guardrail of 120, so no cash guardrail is near.
- I did not add a control for the price response unread (D-011 requests the designer to read it from the sales reports). That is a method change, not a bound.
