## Can the aims be met as the work is done now?
No, not as written. Three things in the current spec and rules hold the work back:
1. **Depot stock is not measured.** The charts have no depot-stock measure, so the constraint cannot be seen. S-001 asks the designer to add one. That is a change to the spec's measures.
2. **Purchasing only at point boundaries.** The spec's cadence orders at days 0, 7, 14, …, with 4–8 day lead times. Stock for slots cannot follow demand on that cadence.
3. **Depot-cover rule starts at day 14.** The spec's v2 check says "from day 14". S-001 asks it to start now. Applying it now means changing a rule the spec sets, which this aim update does not do.

aims.md states the depot-cover step as the Strategist's request, but the spec and rules still say day 14, so the operator is not bound to it yet. Without the change, the slot aim (≥ 18) and the cash floor are unlikely to be met this point.
